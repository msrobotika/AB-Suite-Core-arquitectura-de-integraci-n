LAS NUEVE EN UN PAQUETE

Instalación de AB Suite

Windows 10/11 de 64 bits: instala AB Suite y ábrela desde Inicio. El instalador incluye los motores; no necesitas instalar Node.js ni Python.

Código fuente · Windows, macOS y Linux

La edición de código fuente requiere Node.js 20+ y Python 3.11+. Extrae el ZIP y abre iniciar.bat o ejecuta sh iniciar.sh. La primera preparación del código fuente necesita Internet.

CONEXIONES OPCIONALES

De dónde viene cada señal

PLC se consulta en la CPU residente y sigue disponible al cerrar su vista. Las otras fuentes de navegador necesitan su pestaña abierta. Tras cinco segundos sin actualizar, una señal se muestra caducada.

Hasta 600 muestras observadas mientras este panel está abierto. La captura no controla equipos ni modifica programas.
