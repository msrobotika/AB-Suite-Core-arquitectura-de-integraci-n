# AB BI · AB Suite

Esta es la versión integrada de **AB Suite 0.6.1**, mantenida en este repositorio. [Descargar e instalar toda la suite](../../README.md#descargar-e-instalar). Se puede usar esta herramienta sin abrir las demás.

Espacios propios vacíos, importación CSV/TSV/JSON/XLSX con destino, perfil de calidad, limpieza, SQL, Expresiones AB y gráficos.

**Uso:** abre el catálogo en `http://127.0.0.1:4170`, elige AB BI y pulsa Nuevo para crear trabajo propio. Los ejemplos son opcionales. Nuevo conserva un punto anterior en Proyectos. No abras los HTML aislados.

**Límite real:** SQL de lectura y gramática propia parcial; los ejemplos son opcionales y no sustituyen datos del usuario.
