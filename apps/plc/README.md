# PLC Simulator · AB Suite

Esta es la versión integrada de **AB Suite 0.6.1**, mantenida en este repositorio. [Descargar e instalar toda la suite](../../README.md#descargar-e-instalar). Se puede usar esta herramienta sin abrir las demás.

CPU virtual residente, edición KOP/JSON, observación y ejecución por ciclos. PLC, Modbus y captura BI consultan la misma CPU.

**Uso:** abre el catálogo en `http://127.0.0.1:4170`, elige PLC Simulator y pulsa Nuevo para crear trabajo propio. Los ejemplos son opcionales. Nuevo conserva un punto anterior en Proyectos. No abras los HTML aislados.

**Límite real:** CPU educativa; no programa PLC físicos.
