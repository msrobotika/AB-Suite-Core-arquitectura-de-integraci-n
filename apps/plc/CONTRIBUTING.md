# Contribuciones

1. Explica la necesidad o incidencia en GitHub Issues.
2. Trabaja en una rama y abre una Pull Request.
3. Añade pruebas de regresión para cada cambio del motor.
4. Ejecuta npm run check.
5. Si cambias la UI, adjunta una captura de la aplicación real.

No incorporar librerías propietarias de PLC, firmware protegido, credenciales o código de terceros sin licencia.
