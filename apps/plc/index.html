FLUJO SEGURO
  1. Edita una red.
  2. Añade contactos en serie o paralelo.
  3. Selecciona instrucción y destino.
  4. Valida y carga los cambios.
  5. Comprueba las salidas en el panel de control.
Solo simulación. Los cambios no se ejecutan hasta validarlos. El E-STOP del simulador no es un sistema de seguridad funcional.

Las condiciones complejas no representables conservan sus datos. Para editarlas, utiliza Programa PLC → JSON.

            DOCUMENTACIÓN / QUICKSTART
            
Manual de operación

            

              
01
Ejecuta la simulación
La consola arranca con un ciclo lógico de 100 ms. Puedes pausar, reanudar o reiniciar el PLC virtual.

              
02
Activa la marcha
Pulsa MARCHA para enclavar Q0.0. PARO abre el permiso I0.1; E-STOP abre I0.2 y exige restablecerlo antes del rearranque.

              
03
Observa las piezas
La cinta simula paquetes que cruzan I0.3. El contador CTU suma flancos positivos y enciende Q0.2 al llegar a cinco.

              
04
Edita tus redes
En Programa PLC puedes añadir redes, editar el JSON, validar y exportar. Se admiten AND, OR, NOT, comparaciones, TON, TOF, CTU, SET y RESET.

            

            
Importante: es una plataforma educativa de simulación, no un PLC certificado ni un sistema de seguridad funcional. No conectar salidas a equipos reales, ni sustituir funciones de parada de emergencia.
