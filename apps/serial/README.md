# Serial Analyzer · AB Suite

Esta es la versión integrada de **AB Suite 0.6.1**, mantenida en este repositorio. [Descargar e instalar toda la suite](../../README.md#descargar-e-instalar). Se puede usar esta herramienta sin abrir las demás.

Captura RTU de laboratorio, interpretación de bytes, CRC y exportación; recepción opcional mediante adaptador serie.

**Uso:** abre el catálogo en `http://127.0.0.1:4170`, elige Serial Analyzer y pulsa Nuevo para crear trabajo propio. Los ejemplos son opcionales. Nuevo conserva un punto anterior en Proyectos. No abras los HTML aislados.

**Límite real:** No transmite comandos; hardware y precisión temporal requieren pruebas físicas.
