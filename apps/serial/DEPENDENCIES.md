# Dependencias

Tiempo de ejecución: Python 3.11+, biblioteca estándar y navegador moderno. Para puertos físicos (opcional) pySerial >=3.5,<4. Para el proceso de captura de pantalla en CI (solo desarrollo) Playwright/Chromium. No se distribuye una biblioteca Modbus de terceros ni se hace uso de CDN, servidores externos o telemetría.
