# Seguridad

Versión de laboratorio, no certificada. El motor no incorpora transmisiones TX ni endpoints de escritura. Abrir un puerto físico puede alterar señales DTR/RTS según adaptador. Un adaptador RS-485 convencional no garantiza escuchas pasivas de ambos sentidos. La temporización por USB/OS es aproximada. El servidor escucha únicamente en 127.0.0.1, usa token temporal y bloquea Host/Origin ajenos. No hay nube ni telemetría. Autorización obligatoria para abrir un puerto enumerado. No utilizar para enclavamientos, emergencia o control productivo.
