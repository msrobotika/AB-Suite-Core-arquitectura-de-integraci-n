# Contribuir

Aceptar solo contribuciones originales o bajo licencia compatible MIT. Toda ampliación del lenguaje ST/SCL exige pruebas exhaustivas o equivalencia demostrada, análisis de riesgos y casos de rechazo seguro. No subir código propietario de PLC ni proyectos industriales privados.

Ejecutar tests de Node y Chromium antes de cada pull request.
