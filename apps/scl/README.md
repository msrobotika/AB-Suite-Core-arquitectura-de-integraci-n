# SCL Studio · AB Suite

Esta es la versión integrada de **AB Suite 0.6.1**, mantenida en este repositorio. [Descargar e instalar toda la suite](../../README.md#descargar-e-instalar). Se puede usar esta herramienta sin abrir las demás.

Editor BOOL ST/SCL, diagnóstico y conversión KOP comprobada con tablas de verdad; transferencia al PLC virtual.

**Uso:** abre el catálogo en `http://127.0.0.1:4170`, elige SCL Studio y pulsa Nuevo para crear trabajo propio. Los ejemplos son opcionales. Nuevo conserva un punto anterior en Proyectos. No abras los HTML aislados.

**Límite real:** No implementa ST/SCL completo, bucles ni runtimes de fabricantes.
