# Modbus Studio · AB Suite

Esta es la versión integrada de **AB Suite 0.6.1**, mantenida en este repositorio. [Descargar e instalar toda la suite](../../README.md#descargar-e-instalar). Se puede usar esta herramienta sin abrir las demás.

Lecturas TCP FC01–04, interpretación de tramas y laboratorio; Leer CPU de la suite utiliza su CPU residente.

**Uso:** abre el catálogo en `http://127.0.0.1:4170`, elige Modbus Studio y pulsa Nuevo para crear trabajo propio. Los ejemplos son opcionales. Nuevo conserva un punto anterior en Proyectos. No abras los HTML aislados.

**Límite real:** Las ediciones se limitan a memoria del laboratorio, no a escrituras industriales arbitrarias.
