# GRAFCET Studio · AB Suite

Esta es la versión integrada de **AB Suite 0.6.1**, mantenida en este repositorio. [Descargar e instalar toda la suite](../../README.md#descargar-e-instalar). Se puede usar esta herramienta sin abrir las demás.

Etapas, transiciones y acciones propias, banco de entradas y diagnóstico por evolución.

**Uso:** abre el catálogo en `http://127.0.0.1:4170`, elige GRAFCET Studio y pulsa Nuevo para crear trabajo propio. Los ejemplos son opcionales. Nuevo conserva un punto anterior en Proyectos. No abras los HTML aislados.

**Límite real:** Motor educativo parcial; sin certificación IEC 60848.
